# ISL Communication System - pinned, mutually-compatible dependencies
# Verified together (import + functional smoke test) for Windows 11 + Python 3.12.10.
#
# Why these exact versions:
# - mediapipe 0.10.21 is the last line that still ships the classic
#   mp.solutions.* API (mediapipe>=1.0 removed it) and has native
#   cp312-win_amd64 wheels.
# - protobuf is pinned INSIDE the range mediapipe 0.10.21 itself requires
#   (>=4.25.3,<5). Installing a newer protobuf (5.x/6.x) alongside an older
#   compiled mediapipe is exactly what caused the previous project's
#   "cannot import name 'runtime_version' from google.protobuf" crash -
#   pinning both here prevents pip from ever picking a mismatched pair.
# - numpy is pinned <2 because mediapipe 0.10.21 requires numpy<2.
# - No TensorFlow anywhere in this stack.
